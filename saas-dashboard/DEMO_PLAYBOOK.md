# SaaSly - Demo Recording Playbook

## What You Need
- Screen recorder (OBS Studio free, or built-in: Win+G on Windows, Cmd+Shift+5 on Mac)
- The app running locally (localhost:5173)
- A test account already created

## Recording Script (2-3 minutes)

### Scene 1: Landing Page (10 sec)
- Open the landing page
- Scroll down slowly showing the hero, mockup, features
- Say: "This is SaaSly, a full-stack SaaS subscription dashboard"

### Scene 2: Pricing Page (15 sec)
- Click through to the pricing page
- Show the 3 tiers, toggle monthly/yearly
- Say: "Three-tier pricing with Stripe integration"

### Scene 3: Registration (15 sec)
- Go to /register
- Fill in name, email, password
- Click "Create account"
- Say: "Users register with JWT authentication"

### Scene 4: Dashboard (30 sec)
- Show the dashboard with stats
- Point to API calls, storage, team members
- Show the progress bars and usage percentages
- Say: "Real-time usage tracking with plan limits"

### Scene 5: Billing (20 sec)
- Click Billing in sidebar
- Show subscription status, plan info
- Point to invoice history table
- Say: "Full billing management with invoice history"

### Scene 6: Settings (15 sec)
- Click Settings
- Show profile form, password section
- Say: "User settings with profile management"

### Scene 7: Pricing/Upgrade (20 sec)
- Click Pricing
- Click "Get Started" on Pro plan
- Show the Stripe checkout redirect
- Say: "Stripe-powered payments with real checkout flow"

### Scene 8: Sign Out (5 sec)
- Click sign out
- Back to login page
- Say: "Ready to deploy. Link in the description."

## Tips
- Keep it under 3 minutes
- Use a clean browser (no personal bookmarks visible)
- Dark mode optional but looks professional
- Add background music (low volume) for Fiverr
- Export as 1080p MP4
